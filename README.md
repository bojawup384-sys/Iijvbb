# برق v9 Pro Max — Electric Gold

مساعد للسوق الجزائري والعربي: محادثة بالدارجة والعربية والفرنسية، 10 أدوات جاهزة، نظام نقاط يومي، وترقية Pro بالدينار (v8: أدوات الكود، صانع الألعاب، رفع الملفات، أحدث النماذج).
تطبيق **PWA** — Next.js 16 · Firebase Auth · فريق AI موحّد (Claude + Gemini + DeepSeek + Grok + OpenRouter + Groq) · PostgreSQL (Drizzle) · Chargily Pay.

## 🚀 النشر على Vercel

1. ارفع المشروع إلى GitHub ثم **Import** في Vercel.
2. في **Settings → Environment Variables** أضف المتغيرات (انظر `.env.example`):

| المتغير | إلزامي؟ | الوصف |
|---|---|---|
| `DATABASE_URL` | ✅ | رابط PostgreSQL (Neon / Supabase / Vercel Postgres) |
| `GEMINI_API_KEY` | ✅ | مفتاح من [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| `NEXT_PUBLIC_SITE_URL` | موصى به | نطاقك، مثل `https://barq.example.com` (sitemap وروابط المشاركة) |
| `ADMIN_SECRET` | موصى به | كلمة سرّ (12+ حرفًا) لإنشاء أكواد Pro بدون SQL |
| `CHARGILY_SECRET_KEY` | اختياري | الدفع عبر EDAHABIA / CIB |
| `CHARGILY_MODE` | اختياري | `live` (افتراضي) أو `test` |

3. **Deploy**، ثم **Redeploy** كلما غيّرت المتغيرات.

> ✅ **الجداول تُنشأ تلقائيًا** عند أول طلب — لا حاجة لـ `drizzle-kit push`.
> (اختياري للمطورين: `npm run db:push` يستعمل `DATABASE_URL` من بيئتك.)

## 🎟️ أكواد تفعيل Pro

بدون SQL — اضبط `ADMIN_SECRET` ثم:

```bash
curl -X POST https://YOUR_DOMAIN/api/admin/promo \
  -H "x-admin-secret: YOUR_ADMIN_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"code":"BARQ-VIP","days":30,"maxUses":100}'
```

- كل مستخدم يستعمل الكود الواحد **مرة واحدة** فقط.
- `GET /api/admin/promo` (بنفس الهيدر) يعرض آخر 50 كودًا.

## 💳 الدفع عبر Chargily

1. سجّل في [pay.chargily.com](https://pay.chargily.com) وأضف `CHARGILY_SECRET_KEY`.
2. في لوحة Chargily → Webhooks أضف: `https://YOUR_DOMAIN/api/billing/webhook`
3. الأسعار: **990 دج/شهر** و**9900 دج/سنة** (في `src/app/api/billing/chargily/route.ts`).

## 🚀 ما الجديد في v9

- **مولّد الصور المجاني**: أضف في Vercel المتغيرين `CLOUDFLARE_ACCOUNT_ID` و`CLOUDFLARE_API_TOKEN` (حساب Cloudflare مجاني، Workers AI) فيستعمل نموذج FLUX.1 schnell مجانا ضمن الحصة اليومية، ويُترجم الوصف للإنجليزية عبر Gemini النصي. بدونهما يرجع لـ Gemini للصور (يحتاج فوترة). تعديل صورة مرفوعة يحتاج Gemini المدفوع.
- **مولّد الصور** `/app/images`: وصف نصي ← صورة (Gemini)، 9 أساليب، 5 أبعاد، رفع صورة وتعديلها، تحميل وإعادة توليد. يكلّف نقطة واحدة، وتُردّ النقطة عند الفشل. النموذج الافتراضي `gemini-2.5-flash-image`، ويمكن تغييره بالمتغير `GEMINI_IMAGE_MODEL`. لجعله Pro فقط غيّر `IMAGE_PRO_ONLY` إلى `true` في `src/app/api/ai/image/route.ts`.
- **8 أوضاع شخصية** (مبرمج، باحث، أستاذ، كاتب، خويا بالدارجة، تاجر، مترجم): تُختار من شاشة البداية ويُرسل `persona` للخادم الذي يتحقق من المعرّف ويضيف تعليمات الوضع للـ system prompt (`src/lib/personas.ts`).
- **لوحة الأوامر** `Ctrl/⌘ + K` (وزر البحث في الشريط الجانبي والهاتف): تنقّل، أدوات، أوضاع، قوالب.
- **أوامر السلاش** داخل المحادثة: اكتب `/` ← لخّص، ترجم، اشرح، كود، صحّح، خطة، قارن، SEO…
- **تحت كل رد**: اسمع (قراءة صوتية)، 👍 👎، عدّاد كلمات، وأزرار متابعة بنقرة (اختصر · اشرح أكثر · بالدارجة · En français · جدول).
- **تصميم**: مؤلّف رسائل بحدّ ضوئي متحرّك، حبيبات خفيفة تمنع تدرّج الألوان من التكسّر، عناوين ردود أهدأ، قسم Bento جديد في الصفحة الرئيسية، وشارات عائمة في الـ Hero.

## 🤝 فريق الذكاء الاصطناعي الموحّد (Pro)

أضف أي مفاتيح تملكها (`ANTHROPIC_API_KEY` · `GEMINI_API_KEY` · `DEEPSEEK_API_KEY` · `XAI_API_KEY` · `OPENROUTER_API_KEY` · `GROQ_API_KEY`) — كل محرّك له مفتاح ينضم تلقائيًا.

1. **المسوّدات بالتوازي**: كل محرّك يكتب نسخته الكاملة (مع نصاب: بعد وصول مسوّدتين، يُمنح الباقي 15 ثانية فقط).
2. **الدمج**: المحرّك القائد (الافتراضي Claude، غيّره بـ `BARQ_LEAD`) يدمج أقوى ما في كل المسوّدات ويصلح الأخطاء. إن سقط القائد يتولّى التالي تلقائيًا.
3. **ترميم القطع**: إن انقطع الكود بسبب حد التوكنات يُكمَّل ويُغلق (`</html>` + إغلاق الكتلة) تلقائيًا.

يُفعَّل في: «صانع الألعاب» وطلبات البناء (لعبة / موقع / تطبيق) في المحادثة. مواصفات الملف الواحد (HTML واحد، محرّك واحد، حالات MENU→PLAYING→PAUSED→GAME OVER، صوت Web Audio، localStorage، لمس + كيبورد) مدمجة في `src/lib/prompts.ts` (`WEB_SPEC`). التشخيص: `/api/ai/status` يعرض أسماء المحرّكات المتصلة.

## 🛡️ الأمان

- التحقق من توكن Firebase بالتوقيع (RS256) مع فحص `exp` و`aud` و`iss`.
- خصم النقاط بعملية SQL واحدة (لا تجاوز بالطلبات المتزامنة).
- أكواد الترقية: استعمال واحد لكل مستخدم + حجز ذرّي لعدد الاستعمالات.
- Webhook بتوقيع HMAC، وتفعيل الاشتراك مرة واحدة فقط لكل دفعة.
- الأخطاء الداخلية تُسجَّل في سجلات Vercel ولا تُرسل للمتصفح.
- حد 15 طلب ذكاء/دقيقة لكل مستخدم.

## ⚡ جديد في v7 Pro Max

- **لا يتوقف الكود أبدًا:** حارس إكمال تلقائي على السيرفر (حتى 5 جولات) + إكمال من الواجهة (حتى 4 جولات، بدون خصم نقاط) حتى تُغلق كل الأوسمة والأقواس وكتلة الكود.
- **ذاكرة قوية:** تُرسل المحادثة بذاكرة أطول (حتى 260 ألف حرف) وآخر كود يُحفظ كاملًا، + **ذاكرة طويلة المدى** في `/app/settings/memory` (أو قل «تذكّر أن …» داخل المحادثة) محفوظة في قاعدة البيانات.
- **عقد جودة** للنموذج: مراجعة ذاتية قبل الرد، تعديل من آخر نسخة بدون إسقاط ميزات، لا placeholders.
- **أزرار برق 5 / برق 6** داخل خانة الكتابة، وإرسال/ردّ بتصميم عصري واضح لكل الهواتف.
- **معاينة تلقائية بالشاشة الكاملة** عند انتهاء كود الصفحة/اللعبة (مع كود، أجهزة، حفظ، ZIP).
- **ملف ZIP قابل للتحميل** يظهر مباشرة في الدردشة (يقسّم الصفحة إلى index.html + css + js + README)، و**رفع ملفات ZIP** لتحليل مشروعك كاملًا.
- **الاستوديو في قاعدة البيانات** (`projects`) بدل التخزين المحلي، مع نقل تلقائي للأعمال القديمة.
- **تسجيل واقعي:** تتبّع كل دخول/تسجيل (`login_events`)، مزوّد الدخول، عدّاد الدخول، بريد تأكيد حقيقي، مؤشر قوة كلمة السر.
- **لا صفحة بيضاء:** خلفية داكنة على `<html>`، شاشات تحميل/خطأ/404 جميلة، صفحة offline جديدة، وزر رجوع داخل التطبيق.
- **خلفية حيّة** (aurora) خفيفة على الـ GPU.

> الجداول الجديدة (`ai_memories`, `projects`, `login_events` + أعمدة users) تُنشأ تلقائيًا عند أول طلب.

## ⚡ محرك البناء الحي (v7 Pro Max — الهوية الجديدة)

- **الهوية:** Monochrome Cyber Luxe — أسود ملكي `#050505`، نص أبيض/رمادي، حدود 1px، زجاج معتم. كل الألوان تُدار من التوكنز في أعلى `src/app/globals.css`.
- **الصفحة:** `/app/studio/build` — شجرة ملفات يسارًا، وثلاث طبقات: الكود / المعاينة الحية / التعديل البصري.
- **المعاينة الحية:** تتحدّث أثناء التوليد (Hot-reload) داخل iframe معزول (`sandbox` بلا same-origin) مع CSP يمنع أي اتصال شبكة، ويسمح فقط بسكربتات `cdnjs.cloudflare.com` و`cdn.jsdelivr.net` (مثل Three.js).
- **الإصلاح الذاتي:** أخطاء runtime تُلتقط من المعاينة وتُرسل للمحرك تلقائيًا (جولتان كحد أقصى لكل طلب).
- **التوليد المتصل:** إن انقطع الكود داخل code block يُستأنف تلقائيًا من نقطة التوقف (`continueFrom`).
- **الإدخال:** صوت (Web Speech API) + صورة/سكتش → كود.
- **التصدير:** ZIP منظّم. زر «نشر» ينزّل ZIP ويفتح Netlify Drop (نشر مباشر بنقرة واحدة يحتاج مفتاح API لمزوّد استضافة).
